# 🛍️ sStore (`Shop_project_Django`) — Веб-приложение интернет-магазина

**sStore** — веб-приложение интернет-магазина, разработанное на фреймворке **Django** с использованием **PostgreSQL** и **Bootstrap**. Приложение реализует каталог товаров с версионированием продуктов, загрузку начальных данных через кастомные management-команды, а также систему регистрации и аутентификации пользователей с подтверждением учётной записи по электронной почте (SMTP).

## ✨ Основные возможности

### Каталог и управление данными
* **Витрина и карточки товаров**: просмотр списка товаров и детальных страниц с адаптивным отображением изображений.
* **Версионирование продуктов**: автоматическое определение и отображение активной версии товара (`active_version`).
* **Сервисный слой и кастомные команды**: наполнение и очистка базы данных (`load_category`, `load_product`, `delete_data`), вспомогательная логика в `service.py` и пользовательские шаблонные теги (`my_tags.py`).

### Пользователи и безопасность
* **Кастомная модель пользователя**: авторизация по `email` вместо `username`, дополнительные поля профиля (`phone`, `country`, `avatar`).
* **Верификация по электронной почте**: генерация кода подтверждения при регистрации, отправка ссылки активации через SMTP (с динамической поддержкой SSL/TLS) и активация аккаунта по переходу.
* **Смена и восстановление пароля**: генерация нового пароля для авторизованного пользователя с отправкой на его email.
* **Быстрое создание администратора**: кастомная команда `csu` для создания суперпользователя.

### Модульность
* **Блог (`blog`)**: в кодовой базе сохранено приложение блога из предыдущих версий проекта (модели, контроллеры, маршруты и шаблоны). В текущей конфигурации модуль отключён (`INSTALLED_APPS` / `urls.py`) и при необходимости может быть повторно активирован.

## 🛠️ Технологический стек

* **Backend**: Python, Django 5.2
* **База данных**: PostgreSQL
* **Frontend**: HTML5, CSS3, Bootstrap 5, Django Templates
* **Управление зависимостями**: Poetry
* **Почтовый сервис**: SMTP (`django.core.mail`, Яндекс Почта / любой SMTP-провайдер)

## 🚀 Установка и запуск проекта

### 1. Клонирование репозитория

```bash
git clone https://github.com/edelweiss111/Shop_project_Django.git
cd Shop_project_Django
```

### 2. Установка зависимостей через Poetry

```bash
poetry install
```

### 3. Настройка переменных окружения

Создайте файл `.env` в корневой директории проекта и заполните его по образцу:

```env
# Настройки Django
SECRET_KEY=your-secret-key
DEBUG=True

# Настройки базы данных PostgreSQL
DB_NAME=sstore_db
DB_USER=postgres
DB_PASSWORD=your_db_password
DB_HOST=localhost
DB_PORT=5432

# Настройки SMTP (пример для Яндекс Почты по SSL)
EMAIL_HOST=smtp.yandex.ru
EMAIL_PORT=465
EMAIL_USE_TLS=False
EMAIL_HOST_USER=your_email@yandex.ru
EMAIL_HOST_PASSWORD=your_app_password
```

> **Примечание:** Для работы с Яндекс Почтой или Gmail в качестве `EMAIL_HOST_PASSWORD` необходимо использовать **пароль приложения**, а не основной пароль от учётной записи.

### 4. Подготовка базы данных и начальных данных

Применение миграций:

```bash
poetry run python manage.py migrate
```

Создание суперпользователя (кастомной командой):

```bash
poetry run python manage.py csu
```

Загрузка начальных категорий и товаров (при необходимости):

```bash
poetry run python manage.py load_category
poetry run python manage.py load_product
```

### 5. Запуск веб-приложения

Из терминала с использованием Poetry:

```bash
poetry run python manage.py runserver
```

Либо через конфигурацию запуска **Django Server** в **PyCharm** с выбранным интерпретатором виртуального окружения Poetry.

После запуска приложение будет доступно в браузере по адресу: `http://127.0.0.1:8000/`
